# 🚀 SocialHub AI

A modern social media web application built using **React + Vite** that allows users to create posts, search content, interact with other users, and manage their profiles.

# 📖 Project Overview

SocialHub AI is a responsive social media web application developed as an assessment project. It demonstrates user authentication, post creation, searching, reactions, comments, profile management, and a modern UI.

The project also includes GitHub version control, CI/CD using GitHub Actions, and automatic deployment to Vercel.

---

# 💼 Business Value

SocialHub AI provides a platform where users can:

- Create and share posts
- Search content instantly
- Interact using likes and comments
- Follow users
- Manage their profiles

This helps improve user engagement, communication, and community building, which are key business goals for modern social platforms.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/reddyvinaykarri/socialhub-ai.git
```

Move into the project

```bash
cd socialhub-ai
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

---

# 🔄 CI/CD Pipeline

This project uses **GitHub Actions** for Continuous Integration.

The workflow automatically:

- Installs dependencies
- Builds the React application
- Verifies successful compilation

Every push to the **main** branch triggers the CI workflow.

---

# ☁️ Deployment

The application is deployed using **Vercel**.

Whenever new code is pushed to GitHub, Vercel automatically deploys the latest version.
